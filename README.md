# Dashboard de Misiones Espaciales 🛰️

## Descripción del Proyecto
Este proyecto es una aplicación Front End desarrollada en React que funciona como un Dashboard de Misiones Espaciales. El objetivo es ir construyendo esta aplicación de forma paulatina, repasando características de React y aprendiendo nuevas funcionalidades durante el proceso.

## Dinámica de Trabajo
**Individual**: Este proyecto será desarrollado de forma individual. 
Las decisiones de diseño, arquitectura y desarrollo se tomarán y ejecutarán por el propio desarrollador, manteniendo buenas prácticas de código y versionado.

## Instalación y Configuración
1. Clona el repositorio.
2. Ejecuta `npm install` para instalar las dependencias.
3. Ejecuta `npm run dev` para iniciar el servidor de desarrollo.
